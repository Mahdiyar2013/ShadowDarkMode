# Shadow Dark Mode 🖤💜

A starter client-side Fabric mod for Minecraft Java Edition **1.21.11**.

It adds a subtle dark-purple tint to supported screen backgrounds. This is an early starter version, so the exact screens affected can vary.

## Requirements
- Minecraft Java Edition 1.21.11
- Fabric Loader for 1.21.11
- Fabric API for 1.21.11
- JDK 21 to build the project

## Build locally
Open the project in a Java/Gradle-compatible IDE or terminal and run:

- Windows: `gradlew.bat build` (requires a Gradle wrapper to be present) or `gradle build`
- Linux/macOS: `gradle build`

The compiled JAR is normally created in `build/libs/`.

## Build on GitHub
Push this project to a repository, then open **Actions**. The workflow in `.github/workflows/build.yml` builds the mod and uploads the JAR as an artifact.
